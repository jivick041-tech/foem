這個頁面不含任何通行碼，也不會把資料送到任何伺服器；所有運算都在你的瀏覽器裡完成。

① 產生入場券 QR code

學生掃描 QR code 就會自動帶入通行碼，只需再輸入學號、姓名。QR code 等同通行碼：只發給實驗室成員。

② 更換通行碼（例如學期結束、成員異動、QR 外流）

  1. 輸入目前的通行碼與新通行碼，按「產生新的 content.enc.js」。
  2. 瀏覽器會下載一個新的 content.enc.js。
  3. 到 GitHub repo 用「Add file → Upload files」上傳它，覆蓋舊檔並 Commit。
  4. 幾分鐘後舊通行碼失效，學生下次開啟時會被要求輸入新通行碼。記得重新產生 QR code。
